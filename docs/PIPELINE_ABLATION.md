# PIPELINE_ABLATION —— 训练快照 vs 推理管线：第二层收益从哪来

> 起因：我们发现推理 webui 出的第二层明显好于当年训练 webui 每轮结束的快照，
> 于是做了一次消融来定位原因。
> 方法：固定同一份权重（`diff_v2_masked/ema.pt`）、同一组 10 条 val 条件、
> 同一份初始噪声，逐项切换两条管线之间的差异因素做消融。
> 复现：`python scripts/35_pipeline_ab.py`（约 1 分钟）；产物 `logs/pipeline_ab/`。

---

## 1. 结论（三句话）

1. **第二层变好 100% 是推理框架的收益，权重零变化**——决定性因素是
   **mask 来源**：训练快照用 template 合成模板（椒盐碎屑），推理端用
   retrieval 检索的真实 mask（连通衣物片）。
2. **「第二层」对模型不是条件，是显示层**：该权重 `alpha_input=False`，
   mask 根本不进网络，模型只按 36 维条件向量画 RGB；mask 决定「画好的
   颜色里哪些像素露出来」。
3. **条件向量本身两侧无差异**：训练快照与推理「真实抽样」都取自
   `val_cond`，同源同分布；两侧也无 CFG（cfg=1.0）。

## 2. 为什么训练快照一定是 template（时间线证据）

`models/mask_bank.npz` 生成于 **09-23 23:52**，晚于训练结束
（`ema.pt` 09-23 **18:53**）。训练脚本的采样逻辑是
「`sample_alpha_bank` 有库用库、缺库自动回落 `sample_alpha_templates`」——
所以整个 diff_v2_masked 训练期间（09-22 22:34 起），**每一次 epoch 末
快照的第二层 alpha 都是随机撒点的合成模板**。我们在训练 webui 里看到的
「当时」，就是那个兜底逻辑的产物。

## 3. 消融结果（`logs/pipeline_ab/sheet.png`，第一层/第二层分开渲染）

| 行 | 配置 | 第一层 | 第二层（单独渲染） |
|---|---|---|---|
| 0 | 训练快照原片（09-23） | 完整、正常 | **椒盐碎屑** |
| A | template alpha + 无后处理（=快照口径复刻） | 完整 | **椒盐碎屑** |
| B | = A + 检索真实 mask | 几乎不变 | **连通衣物片，挂在正确位置** |
| C | = B + 自适应量化 K64 | 颜色整固 | 形状几乎不变 |
| D | = C + 破洞修补（DDIM 仍 50） | 补小洞 | 形状几乎不变 |
| E | = D + DDIM 252（=推理实际口径） | 细节略增 | 形状几乎不变 |

* 第一层：五个行几乎一致——第一层观感本来就没变过。
* 第二层：**行 A→B 是决定性跳变**（mask 来源）；C/D/E（量化/修补/DDIM
  步数）是次要观感因素。

## 4. 量化核对（防肉眼误判）

* 训练快照 tile 可见率 43~50%，与当前 template 口径（46.9%）一致
  → 行 A 复刻成立。
* retrieval mask 可见率 ≈ 50.9%，与快照同量级——**差异不在覆盖率，
  在空间结构**：template 逐像素独立撒点（hat 盒连通块中位 1.5px，
  真实 11.5px，历史实测），retrieval 是真实作者的连通图形。

## 5. 对未来训练的启示

* 模型「盲画」第二层（不知道哪里会被露出来）是当前权重的结构性缺口。
* 训练代码里已有对症开关但基本没训过：`--alpha-input`（mask 作第 4 输入
  通道）+ `--ov-bits`（部位级第二层开关）+ `--overlay-weight`（第二层
  梯度只有第一层的 1/6.7）+ `--mask-cross-sample`（防「认出是哪张皮肤」
  捷径）。`drmage_1_v2` 带这些开关只训了 17 轮即被停，**未被公平评估**。
* 推理框架正好补齐另一半：retrieval mask 与训练侧 alpha 同分布，
  使「给定 mask 补内容」在推理时是适定任务——**训练侧加 alpha_input 与
  推理侧 retrieval 是互相成就的一对**。
* 但注意项目既定结论：训练量本身不是解药（17× 训练量仅换 adj_eq
  +1.2 个百分点，见 `logs/_tri_ckpt/report.txt`）；续训前先跑短对照。
