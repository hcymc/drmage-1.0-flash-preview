# MODEL CARD —— drmage-1.0-flash-preview（diff_v2_masked）

> 发布性质：**实验预览（experimental preview）**。
> 本卡遵循模型卡惯例给出「能做什么 / 做得怎样 / 不能做什么」，所有数字
> 都标注了**测量口径**（不同口径的数字不可互比）。

---

## 1. 模型详情

| 项 | 值 |
|---|---|
| 发布名 | `drmage-1.0-flash-preview`（代码内 tag：`diff_v2_masked`） |
| 架构 | 像素空间 DDPM：SmallUNet（base=64, t_dim=256, 自注意力 + FiLM 条件注入） |
| 训练有效参数 | **11.88M**（代码里另有约 1.3M FiLM 层：该权重训练时 FiLM 尚未加入，加载时缺键放行、零初始化等价于无 FiLM——加载逻辑有显式校验，不是静默错配） |
| 扩散设置 | T=1000，cosine schedule，DDIM 50 步（η=0）采样 |
| 条件 | 36 维向量：色相直方图 12 + 色相均值 1 + 饱和/明度均值 2 + 中性/暗/亮/高饱和占比 4 + tone one-hot 4 + 饱和档 3 + 复杂度档 5 + overlay 存在位 1 + 透明占比 1 + 骨架 one-hot 3 |
| 输出 | 64×64 RGB（模型）× alpha（mask 库检索）→ 64×64 RGBA，alpha 严格 0/255 |
| 训练 | 两阶段：`diff_v1`（无掩码损失，~81,400 步）→ `diff_v2_masked`（+ 掩码损失，至 **687,400 步 / 312 epoch** 手动冻结） |
| 损失 | masked MSE（只在可见像素上，overlay 盒不加权）+ AdamW 2e-4 + AMP + EMA(0.9995) |
| 硬件 | 单卡 RTX 2080 SUPER 8GB（batch 48，峰值显存 4.6GB） |
| 训练期 | 2026-09-22 ~ 2026-09-23（含阶段一） |

## 3. 实测指标（发布权重，EMA，DDIM 50，seed 1234，设计最丰富 24 张真实参照）

| 指标（口径：面内相邻边，24 张「第二层最丰富」真实参照） | 真实 | 本模型 | 差距 |
|---|---|---|---|
| `adj_eq`（相邻像素三通道精确相等率） | **0.1802** | 0.0345 | -81% |
| ≥8px 同色连通块占可见像素比 | **0.1388** | 0.0014 | -99% |
| 色熵 | 0.4162 | 0.8676 | +108% |
| 唯一色数 / 图 | 1028 | 1870 | +82% |
| `adj_le8`（相邻差 ≤8 灰阶；口径：随机 256 张对照） | 0.5070 | **0.5258** | **≈ 持平** |

训练损失（masked MSE，可见像素口径）：最终 0.0428，历史最优 0.0410。

**读数怎么理解**：

* `adj_le8` ≈ 真实 ⇒ **大尺度结构与颜色分布已经对齐**，这是「第一层抽奖基本可用」的量化对应；
* `adj_eq` / `≥8px 块` 远低于真实 ⇒ **像素级的「像素画质感」（大片精确同色块）没有学到**，
  输出偏「高频细碎」——这是 `连续 RGB × 回归目标` 的组合性缺陷，
  实测把训练量拉大 17 倍只回收了 1.2 个百分点（0.0157→0.0345），不是训练量能解决的；
* 同一条件下真实分布本身是多峰的（同一段条件对应几百张结构不同的真实皮肤），
  MSE 的解析最优解是这些峰的均值 ⇒ 输出必然偏糊。这是本预览版**已知的、未解决的**核心问题。

## 4. 预期用途 / 不预期用途

**适用**：研究与学习（小数据 / 小显卡上把「数据→训练→生成→验证」整条链路跑通的可复现样本）；
以「抽奖」心态生成第一层可用的皮肤底稿；基于本代码继续实验（条件系统、输出表示等方向）。

**不适用**：

* 对**第二层（overlay：帽子 / 外套 / 裤外层）质量有要求**的场景——
  本版第二层「色系能对、结构乱」，是最大的已知短板；
* 需要 slim（Alex）骨架——训练集里 slim 格式纹理仅个位数，属分布外；
* 任何「成品皮肤工具」级别的期待（见发布性质）；
* 生成用于恶意冒充他人皮肤的内容。

## 5. 限制与偏差

1. **条件信息瓶颈**：36 维条件中 65% 是全局颜色统计；「第二层画什么」
   只有 5 个存在性 bit，空间位置 0 维。同条件多峰 ⇒ 均值解 ⇒ 糊（见 §3 读数）。
2. **骨架单一**：只有 classic。UI 已锁死骨架选项，`slim` 属外推。
3. **`quality_tier` 分不清「精细」和「噪声」**（唯一色数与边缘密度这两个门槛
   恰好被噪声同时拉满）。评估生成质量请看 §3 的分布指标。
4. **数据偏差**：训练集风格分布即上游集合的分布（抽象 / 卡通 / 拟人混杂），
   条件向量对「风格」几乎没有表达；colorful / 灰度等分布也是上游原样。
5. **alpha 是外供的**：模型不学 alpha、也看不到 mask（`alpha_input=False`）——
   它不知道自己画的第二层会在哪里露出；mask 库覆盖不到的形态不会出现；
   alpha 质量上限 = 真实 mask 库的上限。消融实证见 `docs/PIPELINE_ABLATION.md`。
6. 本模型在 **64×64 modern** 格式上训练与验证；不支持 64×32 旧版皮肤。
