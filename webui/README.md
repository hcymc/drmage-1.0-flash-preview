# 训练监控面板（webui/server.py，端口 8848）

`drmage-1.0-flash-preview` 的训练监控 + 训练控制面板。**零第三方依赖**——
只用 Python 标准库起 HTTP 服务、只用原生 canvas 画图表，不引任何 CDN。

```
启动：python webui/server.py
访问：http://127.0.0.1:8848/
```

> 与推理实验台（`webui/infer/server.py`，端口 **8850**）是**两个独立进程**，
> 互不依赖，可同时开。系统指标读取用了 Win32 API，非 Windows 环境下
> 系统面板会显示为空，其余功能不受影响。

---

## 1. 本发布与旧版面板的差异

旧仓库的面板服务于「几十个实验并行迭代」，有实验扫描与切换下拉；
本发布**只面向一个实验 `diff_v2_masked`**，因此：

* 实验列表锁定为 `diff_v2_masked`，不再扫描 `logs/` 下的其它目录；
* 「训练档案」只列 `models/diff_v2_masked/` 的断点（阶段一预训练权重
  `models/diff_v1/` 不进面板，它只出现在复现文档里）；
* 训练预设裁剪为两阶段官方配方（见下）。

## 2. 面板里有什么

| 区域 | 内容 |
|---|---|
| 顶栏 | 训练状态徽章（训练中/已完成/已停止）· 实验下拉（单实验）· SSE 状态 · 告警通知 · 训练启动 / 停止 |
| KPI 行 | 状态（PID/心跳）· 进度（轮次 + 步数 + 进度条）· masked MSE（含 Δ 与历史最优）· 学习率 · 峰值显存 · GPU 利用率 / 温度 · ETA |
| 训练曲线 | 5 个视图：MSE（原始 + 20 点滑动平均）/ 学习率 / 峰值显存 / 逐轮损失与耗时（双 Y 轴）/ 生成质量探针。滚轮缩放、拖动平移、双击复位、导出 PNG |
| 训练样本快照 | 275 张固定噪声快照按步数浏览；「对比首帧」把训练初期与最新并排打开——同一组噪声，差异纯粹来自模型进步 |
| 系统运行状态 | GPU/显存/温度仪表 · CPU/内存/磁盘条形 · 近 1 小时系统曲线 |
| 监控与系统消息 | 事件流：训练启停、逐轮完成、新最优 MSE、MSE 连续上升、新快照/断点、温度/显存/磁盘告警 |
| 关键指标速览 | 数据集规模等聚合信息 |
| 训练档案 | 完整训练配置 + 断点列表 |
| 底部标签页 | 中文日志（逐行解析成人话）/ 训练进度表 / 服务日志 |

## 3. 从面板启动训练（两阶段官方配方）

预设即 `docs/REPRODUCE.md` §3 的固化：

| 预设 | 命令行等价 | 用途 |
|---|---|---|
| **阶段二 · diff_v2_masked 官方配方** | `--cond --mask-loss`（+ 断点填 `models/diff_v1/latest.pt`） | 复刻发布权重 |
| **阶段一 · 预训练（diff_v1 配方）** | `--cond --no-mask-loss` | 两阶段链条第一步 |

防呆设计：

* 启动前会校验当前解释器有 CUDA——没有就直接拒绝并提示正确命令
  （CPU 版 torch 会**静默**把训练拖慢一个数量级，日志看不出异常）；
* 续训断点只允许 `models/` 下的文件，防任意路径；
* 子进程以 `CREATE_BREAKAWAY_FROM_JOB` 启动，脱离父进程的作业对象——
  从 IDE / 自动化会话里启动面板时，训练不会被「连坐」杀掉；
* 心跳机制：训练脚本每 100 步 / 每轮写 `logs/<tag>/heartbeat.json`，
  面板用 **PID 存活 + 心跳**双信号判断「在跑 / 已停 / 异常中断」。

## 4. 随仓库附带的训练历史

仓库自带 `logs/diff_v2_masked/`（687,400 步完整记录）与
`logs/samples/diff_v2_masked/`（275 张快照），所以第一次打开面板就能看到
真实的训练全程——包括曲线、逐轮耗时、显存轨迹与快照演化。

历史心跳被标记为「已停止（作者手动冻结为发布权重）」：
原始终止方式是手动停止而非跑满目标轮数，面板状态与归档注释都如实标注。

## 5. 数据来源

* 状态/曲线/日志：只读 `logs/<tag>/`（metrics.jsonl / heartbeat.json / train.log）
* 快照：只读 `logs/samples/<tag>/`
* 断点：只读 `models/<tag>/`
* 唯一写入：`webui/` 自己目录下的 `events.jsonl` / `system_history.json` / `server.log`
