抽奖模式

预计耗时 —

从 val 集抽 N 条真实条件各生成一张，由学习型评分器 （小判别器：真实皮肤 vs 生成皮肤，评分 = P(像真的)；缺权重时回落手搓规则分） 挑出「最终输出」张。评分依据与训练见 docs/LOTTERY.md。 种子相同 → 结果一致；批量只影响速度与显存，不影响抽中的结果 （差异仅为 GPU 浮点噪声）。建议保持「自适应量化」开启—— 不量化的原始输出色数会爆到 1000+，观感和评分都差。

后处理

第一层里被不透明像素包围的孤立/小片透明（游戏里渲染成「皮肤破洞」） 用周围颜色的均值逐层填上；连续空白逐层向内推进，避免糊成平均色。 第二层的留空是合法状态，不会被碰。面积 >20px 的整片留白视为合法结构，保留。
